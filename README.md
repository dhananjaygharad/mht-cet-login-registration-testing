# MHT-CET Manual Testing Project

This repository contains manual testing documentation for the MHT-CET website focusing on the Login and Registration pages.

## Project Modules
1. MHT-CET Login Page
2. MHT-CET Registration Page

## Test Artifacts Included
- Test Scenarios
- Test Cases
- Bug Reports
- Screenshots of the tested pages

## Tools Used
- Manual Testing
- Microsoft Excel
- Web Browser

## Purpose of the Project
The purpose of this project is to demonstrate manual testing skills by creating structured test scenarios, detailed test cases, identifying bugs, and documenting them properly.
